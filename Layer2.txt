We can horizontally scale stateless API servers.

Playback traffic is completely different
1 viewer might request 15 segments / minute
1 million it becomes 15 × 1,000,000
=
15 million segment requests / minute
roughly 250,000 segment requests / second
CDN absorbs playback workload

Cache locality becomes extremely important

This improves:
latency
throughput
origin protection

But there's an interesting problem with live streaming
LIVE
 │
 ├── segment001
 ├── segment002
 ├── segment003
 └── segment004 ← currently being produced

creates tension:
Long cache lifetime
        ↕
Fresh live content

If cache too aggressively : Users see stale content
If no cache: Origin gets hammered
Consistency, freshness, latency and scalability are constantly fighting each other.
