User Journey :
1. User opens app
        ↓
2. Authenticate
        ↓
3. Fetch catalog
        ↓
4. User selects movie
        ↓
5. Request playback authorization
        ↓
6. API returns playback information
        ↓
7. Player obtains manifest
        ↓
8. Player requests segments
        ↓
9. CDN serves segments
        ↓
10. Player continuously requests next segments

Problem 1

What happens when 10 million people watch the same cricket match?

That leads us to:

CDN + caching + live streaming + origin scaling.

Problem 2

What happens when 100,000 people upload videos?

That leads to:

queues + worker pools + scheduling + GPU/CPU capacity.

Problem 3

What happens when a transcoding worker crashes halfway through?

That leads to:

idempotency + retries + job state + checkpoints.

Problem 4

How does the player know whether to request 1080p or 480p?

That leads to:

adaptive bitrate algorithms + bandwidth estimation + buffering.

Problem 5

How do we stop someone from downloading content they haven't paid for?

That leads to:

authentication + authorization + signed URLs/tokens + DRM concepts.

Problem 6

How does Hotstar know what you want to watch?

That leads to:

event collection + recommendation systems + feature pipelines + ranking.

Problem 7

How do millions of users search the catalog?

That leads to:

search indexing + ranking + caching.

Problem 8

How do we keep the service alive if an entire region fails?

That leads to:

multi-region architecture + replication + failover + disaster recovery.
